# myCrudGpt 2.7.0 — CRUD API Generator

- REST API versionate `/api/v1`
- Controller API sottili basati su Service e Query Layer 2.6.1
- Resource per whitelist campi leggibili/scrivibili
- esclusione automatica campi sensibili
- paginazione, ricerca, filtri e ordinamento sicuri
- PUT e PATCH distinti
- risposte JSON uniformi data/meta/links ed error
- soft delete API opzionale
- OpenAPI YAML per risorsa
- comando `php spark mycrud:check-api <table>`

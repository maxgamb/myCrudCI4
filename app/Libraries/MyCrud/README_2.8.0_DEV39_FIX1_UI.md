# myCrudGpt 2.8.0-dev39 fix1 UI

Correzione UX del Form Sections Builder.

## Sezioni

- cancellazione sicura delle sezioni;
- i campi di una sezione eliminata vengono spostati in `Senza sezione`;
- handle dedicato per il drag delle sezioni;
- pulsanti alternativi su/giù per il riordino;
- area di drop evidenziata durante il trascinamento;
- `Senza sezione` non è una card applicativa: nel form generato i relativi campi vengono renderizzati direttamente nella griglia standard.

Nessuna modifica a upload, ServiceExtension o comportamento CRUD.
